# 🚀 **FISIEI - Gestión de Eventos Académicos**  
**Digitalizando la excelencia académica: La plataforma central para la administración y certificación de cursos y eventos de la FISIEI.** 🎓🌟

---

## 🌟 **Resumen del Proyecto**  
Este sistema es una **solución integral** para la **Facultad de Ingeniería en Sistemas, Electrónica e Industrial (FISIEI)**, diseñada para gestionar de principio a fin todos sus ofrecimientos académicos: desde cursos intensivos con notas de aprobación, hasta congresos y webinars con registro de asistencia.  

---

## 🎯 **Nuestro Propósito**  
**📋 Administración Centralizada**: CRUD eficiente para eventos, participantes y organizadores.  
**👩‍💻 Experiencia de Usuario**: Proceso de inscripción fluido y búsqueda avanzada.  
**🤖 Automatización**: Gestión de pagos y generación instantánea de certificados.  

---

## ✨ **Características Destacadas**  
| **🔑 Característica**              | **📖 Descripción**                                                                 |
|-----------------------------------|-----------------------------------------------------------------------------------|
| **🎭 Gestión de Roles**           | Soporte para **Administradores** (control total y aprobación de pagos) y **Participantes** (inscripción y perfil). |
| **💸 Flujo de Pago con Validación** | Permite pagos por **Depósito/Transferencia**, requiriendo que el usuario suba un comprobante que debe ser aprobado manualmente por un **Administrador**. |
| **🎟️ Tipos de Evento Flexibles**   | Manejo de **Cursos** (con notas y horas), **Conferencias**, **Webinars** y **Socializaciones** (solo asistencia). |
| **🏅 Certificación Automática**    | Generación de **certificados** de Asistencia o Aprobación, basados en el registro de asistencia y/o la nota final. |
| **🔍 Búsqueda Inteligente**         | Filtros avanzados por **Carrera**, **Tipo de Evento**, **Categoría** y **Número de Horas**. |
